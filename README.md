# ClinicAppointmentBooking

First: How to run the application:

1. Make sure you have Docker desktop (WSL 2 required)
2. Open the GitHub repository and save the project on your device
3. After you have saved the project, right click on it and choose "Open in terminal"
4. Run the following command: docker compose up --build -d
5. The terminal should show at the end these lines:
  Container clinic-web                 Running                                                                     
  Container clinic-api                 Running
6. Open a browser and go to: http://localhost:8080/
7. Now you can use the application and test it.


Second: The choices I made:

I went to build the application as:
Backend/xUnit tests: C# with ASP.NET Core framework
Frontend: Typescript with Angular framework
Database: SQLite
