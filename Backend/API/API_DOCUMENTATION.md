## 🏥 Clinic Working Rules & Business Constraints

1. **Clinic Operating Days**: Sunday through Thursday. The clinic is **closed on Fridays and Saturdays**.
2. **Working Hours**: **08:00 to 16:00** local time.
3. **Slot Duration**: Exactly **30 minutes**. Appointments must align to `:00` or `:30` minute marks.
4. **Booking Window**: Available dates can be booked from **today** (if current time is before 16:00) or **tomorrow** up to **1 month ahead**.
5. **Double Booking Prevention**: An appointment slot cannot be reserved if already booked by another patient for the same doctor.
6. **Past Dates**: Appointments cannot be booked or cancelled for dates/times in the past.
7. **Cancellations**: Requires both `appointmentId` and matching `patientId` for patient ownership verification. Already cancelled appointments cannot be cancelled again.

## 📖 Endpoint Details

### 1. Get All Doctors
Retrieves all registered clinic doctors sorted alphabetically by first and last name.

- **Method**: `GET`
- **URL**: `/api/Appointments/doctors`
- **Responses**:
  - `200 OK`: Array of doctor records.

#### Example Response:
```json
[
  {
    "id": 1,
    "firstName": "Daniel",
    "lastName": "Wilson",
    "specialty": "Orthopedics"
  },
  {
    "id": 2,
    "firstName": "Emily",
    "lastName": "Carter",
    "specialty": "Pediatrics"
  },
  {
    "id": 3,
    "firstName": "James",
    "lastName": "Anderson",
    "specialty": "Cardiology"
  },
  {
    "id": 4,
    "firstName": "Michael",
    "lastName": "Roberts",
    "specialty": "Neurology"
  },
  {
    "id": 5,
    "firstName": "Sarah",

```

```bash
curl -X GET "http://localhost:5246/api/Appointments/doctors" -H "Accept: application/json"
```

### 2. Get Selectable Booking Dates
Returns available booking dates (`YYYY-MM-DD`) within the next 30 days, excluding Fridays and Saturdays.

- **Method**: `GET`
- **URL**: `/api/Appointments/dates`
- **Responses**:
  - `200 OK`: Array of date strings.

#### Example Response:
```json
[
  "2026-11-17",
  "2026-11-18",
  "2026-11-19",
  "2026-11-22",
  "2026-11-23"
]
```

#### Example cURL:
```bash
curl -X GET "http://localhost:5246/api/Appointments/dates" -H "Accept: application/json"
```

---

### 3. Get Doctor's Day Schedule
Returns 30-minute intervals between 08:00 and 16:00 for the specified doctor and date with an `isAvailable` flag.

- **Method**: `GET`
- **URL**: `/api/Appointments/doctors/{doctorId}/schedule?date={date}`
- **Parameters**:
  - `doctorId` *(path, integer, required)*: The doctor's ID.
  - `date` *(query, string [date], required)*: Date in `YYYY-MM-DD` format.
- **Responses**:
  - `200 OK`: Array of time slots.

#### Example Response:
```json
[
  { "time": "08:00", "isAvailable": true },
  { "time": "08:30", "isAvailable": true },
  { "time": "09:00", "isAvailable": false },
  { "time": "09:30", "isAvailable": true },
  { "time": "15:30", "isAvailable": true }
]
```

#### Example cURL:
```bash
curl -X GET "http://localhost:5246/api/Appointments/doctors/1/schedule?date=2026-11-18" -H "Accept: application/json"
```

---

### 4. Book an Appointment
Creates a patient profile and reserves an appointment slot.

- **Method**: `POST`
- **URL**: `/api/Appointments/book`
- **Content-Type**: `application/json`
- **Responses**:
  - `201 Created`: Booking created successfully. Contains the `Location` header.
  - `400 Bad Request`: Validation failure or slot taken.

#### Request Body (`BookAppointmentRequest`):
```json
{
  "doctorId": 1,
  "startTime": "2026-11-18T09:00:00",
  "patientFirstName": "John",
  "patientLastName": "Doe",
  "patientPhoneNumber": "+1-555-0199",
  "patientDateOfBirth": "1992-04-15"
}
```

#### Success Response (`201 Created`):
```json
{
  "message": "Appointment booked successfully. Your Patient ID is 1 — save it to view your appointments.",
  "appointmentId": 1,
  "patientId": 1
}
```

#### Error Response (`400 Bad Request`):
```json
{
  "error": "This time slot was just booked by someone else."
}
```

#### Example cURL:
```bash
curl -X POST "http://localhost:5246/api/Appointments/book" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "doctorId": 1,
    "startTime": "2026-11-18T09:00:00",
    "patientFirstName": "John",
    "patientLastName": "Doe",
    "patientPhoneNumber": "+1-555-0199",
    "patientDateOfBirth": "1992-04-15"
  }'
```

### 5. Get Patient Appointments
Retrieves all appointments (upcoming, completed, cancelled) for a patient.

- **Method**: `GET`
- **URL**: `/api/Appointments/patients/{patientId}/appointments`
- **Parameters**:
  - `patientId` *(path, integer, required)*: Patient ID returned from booking.
- **Responses**:
  - `200 OK`: Array of appointment objects.

#### Example Response:
```json
[
  {
    "appointmentId": 1,
    "doctorId": 1,
    "doctorName": "Daniel Wilson",
    "doctorSpecialty": "Orthopedics",
    "startTime": "2026-11-18T09:00:00",
    "appointmentStatus": "Upcoming"
  }
]
```

#### Example cURL:
```bash
curl -X GET "http://localhost:5246/api/Appointments/patients/1/appointments" -H "Accept: application/json"
```

---

### 6. Cancel an Appointment
Cancels an upcoming appointment. Requires patient ID verification.

- **Method**: `DELETE`
- **URL**: `/api/Appointments/cancel`
- **Content-Type**: `application/json`
- **Responses**:
  - `200 OK`: Appointment cancelled successfully.
  - `400 Bad Request`: Permission denied, not found, in past, or already cancelled.

#### Request Body (`CancelAppointmentRequest`):
```json
{
  "appointmentId": 1,
  "patientId": 1
}
```

#### Success Response (`200 OK`):
```json
{
  "message": "Appointment cancelled successfully."
}
```

#### Error Response (`400 Bad Request`):
```json
{
  "error": "Permission denied."
}
```

#### Example cURL:
```bash
curl -X DELETE "http://localhost:5246/api/Appointments/cancel" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "appointmentId": 1,
    "patientId": 1
  }'
```
